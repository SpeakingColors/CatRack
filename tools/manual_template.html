CatRack

Manual for version @VER@. Studio 87. Free and open source (AGPL-3.0-or-later). Collects nothing, never uses the network.

CatRack is a rack plugin (VST3). It holds up to 12 effect units from the Studio 87 suite in one window: compressors, equalizers, saturators and creative effects. Put them in any order, run two side by side as a parallel pair, bypass or solo each one, and save the whole chain as a preset. The units run inside CatRack as built-in code; CatRack never loads other plugin files.

TLDR. Press + Add unit, pick a unit, tweak its six knobs in the panel on the right, drag units by their grip to reorder, and use the preset bar for ready-made chains.

Quick start

  • Open the preset bar and load Start Here, or press + Add unit to build your own chain.
  • Click a unit to select it. Its six controls appear in the unit panel on the right.
  • Drag a unit by the grip on its left to move it. Drop it on the top or bottom edge of another row to put it before or after; drop it on the middle of another unit to run the two side by side.
  • ON, Solo and Mute are on every unit. Press B to bypass the whole rack and compare with the dry sound.
  • Watch the meters on the right: input on the left pair, output on the right pair, in dB.

Signal flow

Input trim, then the rows from top to bottom, then output trim. A row holds one unit, or two units side by side (a parallel pair: both hear the same input, each lane has its own level, and the pair has a Dry/Wet). The signal path strip at the top shows the order and the level after each row.

Latency. The reported latency is the sum over the rows of the largest unit latency in the row. Every path is delayed to line up, so switching a unit off, soloing or muting it never shifts the timing. The host is told the exact figure and it is updated when the chain changes.

Your own presets are plain text files you can back up or share:

  • Linux: ~/.local/share/Studio 87/CatRack/presets
  • Windows: %APPDATA%\Studio 87\CatRack\presets
  • macOS: ~/Library/Application Support/Studio 87/CatRack/presets

The preset browser has search, type chips (including Mine), Load, Rename, Delete, Export and Import. Save asks before overwriting. The loaded preset name and the plugin settings (look, bubbles, power saving, window size) are saved with the project.

Install and uninstall

  • Windows: run the installer. It puts the VST3 in the common VST3 folder and adds an uninstaller (Settings, Apps). Close your DAW first.
  • macOS: open the package. The plugin goes to /Library/Audio/Plug-Ins/VST3, and "Uninstall CatRack" goes to Applications.
  • Linux: for a Flatpak DAW install the Flatpak extension file; for a native DAW unpack the tarball into ~/.vst3.
Why a warning may appear: the installers are not signed with a paid publisher certificate. Windows SmartScreen and macOS Gatekeeper warn about any unsigned installer. On Windows choose "More info", then "Run anyway". On macOS open System Settings, Privacy and Security, and choose "Open Anyway". You can check the files against SHA256SUMS in the zip.

Under the hood

Hosting. Each unit is the pure C++ core of the matching Studio 87 plugin (copied into this repository, same licence), driven through a small common interface. Control values go through one set of six generic automatable parameters per slot; the name and text of each parameter follow the unit that is in the slot.

Smoothing and safety. Parameters are smoothed (5 to 20 ms), the rack processes in chunks of at most 256 samples, structure changes are published without locking the audio thread, and removed units are freed on the message thread after a delay. NaN and infinity are removed before the output.
